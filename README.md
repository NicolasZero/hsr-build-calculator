# Build - Calculator

Herramienta para decidir que artefactos o soportes usar con un personaje de Honkai: Star Rail.

## Funcionalidades del programa planeadas

### 🔹 Registrar un personaje

Se calcula la estadistica de un personaje sumando las estadisticas base del personaje y las estadisticas de los artefactos y soportes.

### 🔹 Comparador de artefactos y soportes (Por implementar)

Comparas diferentes piezas de artefactos o soportes entre si para ver cual es mejor.

### 🔹 Calcular el daño (Por implementar)

Se calcula el daño que hace un personaje con una build.

### 🔹 Calcular la velocidad y los turnos (Por implementar)

Se calcula la velocidad del personaje y cuantos turnos hace en un ciclo.

## Futuras funcionalidades

- Calculadora de ruptura y ultraruptura
- Recomendaciones de artefactos y soportes

## Desarrollado con:
- Vite
- React
- TypeScript
- Tailwind CSS
- Shadcn UI

## Comandos

Ejecutar en la terminal:

```bash
pnpm run dev
```

Crear un build:

```bash
pnpm run build
```

Iniciar build local:

```bash
pnpm run preview
```

# Build - Calculator

Herramienta para decidir que artefactos o soportes usar en un personaje de Honkai: Star Rail.

## Funcionalidades del programa

### 1.- Calcular estadisticas del personaje

Se calcula la estadistica de un personaje sumando las estadisticas base del personaje y las estadisticas de los artefactos y soportes.

### 2.- Comparador de artefactos y soportes

Comparas diferentes piezas de artefactos o soportes entre si para ver cual es mejor.

### 3.- Calcular el daño

Se calcula el daño que hace un personaje con una build.

### 4.- Conversor de estadisticas

Transforma las estadisticas planas a porcentajes y viceversa.

## Futuras funcionalidades

- Calculadora de probabilidad de golpe crítico y daño crítico.
- Calculadora de probabilidad de críticos y críticos basado en la prob. crítico y daño crítico.

## Desarrollado con:
- Vite
- React
- TypeScript
- Tailwind CSS
- Shadcn UI

## Comandos

Ejecutar en la terminal:

```bash
pnpm run dev
```

Crear un build:

```bash
pnpm run build
```

Iniciar build local:

```bash
pnpm run preview
```
